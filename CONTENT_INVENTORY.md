# Content inventory

| Content                              | Evidence and approval needed                                               | Publication status |
| ------------------------------------ | -------------------------------------------------------------------------- | ------------------ |
| Identity, education and employment   | Owner-approved name, dates, education, GPA decision and job facts          | Pending            |
| Résumé                               | Authoritative PDF, update owner and approval of HTML summary               | Pending            |
| Public contact and profiles          | Owner-approved addresses and links                                         | Pending            |
| Project and competition case studies | Source evidence, contribution, dates, outcomes and reviewed project status | Pending            |

For each record, capture the source, verification date, owner approval, permitted public fields and publication status. The scaffold contains the project title and generic portfolio description.
